# Superficie: juego completo (index.html)

- **Modo:** Operate. El jugador completa una tarea: gobernar 17 decisiones y mantener cuatro pilares.
- **Público:** estudiantes universitarios y docentes en formación, en aula o taller, en móvil o proyección.
- **Trabajo:** leer el dilema, comparar A/B/C, decidir y leer el efecto en los cuatro pilares; entender los trade-offs.
- **Acción:** elegir una de tres vías sin que ningún pilar llegue a 0 %.
- **Contenido:** 17 expedientes ODS, tres poderes, bitácora, reacciones de prensa.
- **Restricciones:** HTML estático, CSS propio y JavaScript vanilla; sin backend ni persistencia; español; no cambiar lógica, IDs, textos de contenido ni flujo de juego.
